Cafe Simulator ☕

Project Overview: 
Cafe Simulator is a web-based cafe ordering system developed as a BCA academic project. It allows customers to browse menu items, add products to their cart, and place orders.

Technologies Used: 
HTML
CSS
JavaScript
Node.js
Express.js
MongoDB

Key Features: 
Customer login
Coffee and snacks menu
Add and remove cart items
Automatic total calculation
Order placement
MongoDB database integration
Admin panel to view and manage orders

Project Purpose: 
The main objective is to simplify the cafe ordering process through a user-friendly web application.

Future Enhancements: 
Online payment gateway
Order tracking
Improved user authentication
Project Type: BCA Academic Project
